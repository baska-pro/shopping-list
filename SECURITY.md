# Security Policy

Security fixes are applied to the latest version on the `main` branch.

Please do not publish credentials, private URLs, room keys, account details, or personal shopping data in public issues.

When reporting a vulnerability, include the affected version, reproduction steps, impact, and any suggested mitigation.

For cloud synchronization, use only public client credentials intended for browser use. Keep administrative credentials outside the application and outside the repository. Treat sync room keys as private passphrases.

Screenshots stored in `assets/screenshoot/` must not expose credentials, private URLs, account identifiers, or personal data.
